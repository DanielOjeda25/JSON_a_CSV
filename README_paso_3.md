# Paso 3: validación completa y cálculo de ventas

Este archivo muestra cómo:

1. validar una venta completa
2. rechazarla si hay errores
3. calcular subtotal, descuento y total
4. descontar stock después de una venta válida

## Cómo probarlo

Desde la carpeta `tarea2` ejecuta:

```bash
python paso_3.py
```

## Objetivo

Llegar a la lógica central del programa: aceptar solo ventas correctas y calcular su impacto financiero.
