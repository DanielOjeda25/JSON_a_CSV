# Paso 1: lectura de JSON y extracción de ventas anidadas

Este archivo muestra cómo:

1. leer `inventario.json` y `ventas.json` con `json.load()`
2. recorrer estructuras anidadas recursivamente
3. guardar las ventas en una lista plana
4. crear un diccionario para consultar productos por ID

## Cómo probarlo

Desde la carpeta `tarea2` ejecuta:

```bash
python paso_1.py
```

## Objetivo

Preparar los datos para poder validarlos y procesarlos en pasos posteriores.
